# Desbloqueos de cuenta

El operador puede registrar concesiones explícitas en account_ship_grants de D1. Solo la sesión Google verificada recibe las naves concedidas a su player_id; no se acepta un ID elegido por el cliente. Esta primera versión permite Obsidian en el cliente y no cambia la receta pública de 750 núcleos.

Al entrar a PvP con la nueva versión, se añade ownedShips.obsidian=true al guardado local normal o QA correspondiente. Se respalda el guardado exacto antes de modificarlo y se preservan nivel, experiencia, monedas, materiales, misiones, nave equipada y demás campos. No se resta ningún coste ni se recupera una copia nube antigua. La lista de equipo se recalcula después de aplicar el permiso y la nave aparece al abrir el hangar.

La concesión persiste en la cuenta y puede volver a aplicarse al iniciar una sesión en otro dispositivo que ya tenga una partida. No crea una partida vacía. La propiedad ya concedida no se elimina simplemente al borrar el permiso: ese registro controla nuevas aplicaciones, no revoca inventario local existente.

Instalar la APK nueva sobre la anterior, sin borrar datos. Entrar a PvP con la cuenta autorizada y abrir el hangar para equipar. Si se ofrece elegir entre una copia nube anterior y el progreso actual, conservar la partida actual del dispositivo.
